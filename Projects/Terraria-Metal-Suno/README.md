# Terraria Metal — Suno music project

A separate project for a new Terraria music replacement pack. The original CAMS Music Pack remains under `ResourcePacks/CAMS Music Pack`.

This project currently contains 104 Suno Styles prompts and research notes. No music has been generated, and this folder is not an installable resource pack yet.

## Use the prompts

- Open **Terraria-Metal-Suno.html** in a browser for search, filters, and Copy Styles buttons. Download the folder to use the HTML locally; GitHub's file view displays its source.
- Read **Terraria-Metal-Suno-Prompts.md** directly on GitHub for every prompt, source links, and special cases.
- **prompts.json** contains the structured prompt list, IDs, intended filenames, and coverage notes.
- **tracks.txt** holds the base creative style text in ID order, 1–104.

In Suno, use Custom mode, enable Instrumental, leave lyrics blank, and paste a complete prompt into Styles. The prompts describe metal arrangements and atmosphere; text alone does not reproduce the original melodies.

## Scope

Includes the main soundtrack, 27 Otherworldly tracks, newer boss themes, ambience layers, and intro variants. Intro pairs 50/51 and 102/103 should share master arrangements. Rain and wind ambience in slots 28 and 45 should remain quiet background layers.

The old-pack coverage flags record the local CAMS pack inventory on 11 October 2026, not a playback check or an assertion that the repository copy is identical.
