# Terraria metal music — Suno prompt book

104 replacement slots for the current PC game, including 27 Otherworldly tracks, two ambience layers and intro variants. This is a prompt collection, not a compiled resource pack. CAMS Music Pack has not been modified.

## Use in Suno

1. Open Custom mode and enable Instrumental. Leave lyrics blank.
2. Copy one complete Styles prompt below into the Styles field. Use its track name as the title.
3. If Advanced Options provides Exclude, enter: vocals, singing, spoken word, rap, crowd chants, long silence.
4. Generate candidates and compare the melody, energy and atmosphere with the source track. Revise one musical feature at a time.
5. Save the chosen audio using the listed Music_ID name later. Asking for a loop does not guarantee seamless audio; trim and test loop points before pack assembly.

These prompts target metal arrangements suited to each game's musical setting. Text alone does not supply the original melody and cannot guarantee an exact cover. I researched written descriptions; I have not listened to or measured every original. Tempo words are proposed directions, not measured BPM. The old pack was inventoried as a naming and coverage reference, not analyzed by listening.

The prompt wording and metal choices are original creative recommendations. The music catalogue and its written descriptions informed the research. Some originals use voices or choir; this collection consistently requests instruments. Alt Queen Bee has no written musical description in the current music table, so its prompt is explicitly an artistic proposal.

## Pack reference

The old pack contains 44 audio files: 30 match the current Music_N naming convention exactly, 13 have letter suffixes, and one is named Music_08.mp3 instead of Music_8.mp3. The 30 exact matches are marked below; these are coverage checks only, not playback verification. That leaves 74 current slots without an exact filename match. Its metadata says 31 of 90, an older target count.

Pair 50/51 and 102/103 from the same master audio. Treat 28 and 45 as quiet ambient sound beds, since they can accompany the main music. No separate original song is needed for an intro variation.
